# 本地通话录音工具·升级版

Windows 桌面端微信通话录音工具。微信通话接通后自动录制，挂断后保存 MP3；可以在本机免费转成文字稿，也可以自行配置 AI 服务来整理和追问内容。

## 下载与使用

请从本项目的 **Releases** 下载 `本地通话录音工具-*-win64.zip`。GitHub 页面右侧的“下载源码 ZIP”不含运行时和语音模型，不能直接运行。

1. 将发行 ZIP 完整解压到自己的文件夹，例如“文档”中的一个新文件夹；不要只在压缩包里双击脚本。
2. 双击 `启动录音工具-升级版.vbs`。软件会常驻系统托盘；双击托盘图标可打开窗口。首次使用，到“录音状态”打开自动录音。
3. 微信桌面版通话结束后，在“我的通话”查看录音，并可生成本地文字稿。
4. 若要使用智能校对、AI 分析或问答，再到“设置 → AI 服务”填写自己的服务地址和密钥。这些功能可能产生服务商费用。

解压后请保留整个文件夹，包括 `runtime`、`models` 和 `assets`。升级前先从旧版托盘菜单退出旧程序，再把新版解压到新目录；不要直接覆盖旧目录中含个人数据的文件。需要旧录音时，可在旧版界面打开录音文件夹后自行迁移。录音、配置与日志默认保存在软件目录，因此请选择有写入权限的位置，不要放在 `C:\Program Files`。

## 适用环境

- 64 位 Windows 11，或支持应用进程回环的 Windows 10 build 20348 及以上版本；需要桌面版微信和可用麦克风。
- 中文 OCR 语言包影响联系人昵称识别；缺少时录音仍可保存，但名称可能显示为“未知联系人”。
- 首次启动无需安装 Python，也无需配置 AI 服务。录音与本地转写在本机处理；明确选择云端转写时会上传音频，AI 整理和问答会发送文字给所配置的服务商。

进程级捕获的是微信进程树的声音，可能包含同一进程内的提示音等，不保证只包含通话人声。若捕获失败，软件会报错，不会自动改为录整台电脑的声音。

本软件是独立项目，不代表微信官方。录音前请遵守所在地的适用规则，并尊重通话参与者的隐私。

## 隐私与发布包

公开源码及发行包均不得包含 `config.json`、录音、文字稿、日志或个人备份。本仓库的 `.gitignore` 和 `制作发行包.ps1` 分别对源码提交与发行包采取排除和白名单复制。发布前仍需检查 ZIP 内容。

## 开发者

仓库只保存应用源码和图标。GitHub 对单个普通 Git 文件有 100 MB 限制，因此约 800 MB 的 Windows 内置运行时与本地语音模型放在 Release 下载包内；仓库源码 ZIP 不是可运行软件。发行包在已配好运行时和模型的 Windows 开发目录中执行 `制作发行包.ps1` 生成。

第三方组件及语音模型的来源和许可见 [第三方组件说明](第三方组件说明.md)。
